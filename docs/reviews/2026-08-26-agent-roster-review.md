## 0. Verdict in one paragraph

**The roster is operable from the documents alone for the happy path and most failure paths, and its efficiency floor holds** — every scenario-1 step walks with a named actor, identity, grant and artifact home; no agent needs a capability its row denies; pick/consume/close/land are call-free; no model call is redundant with an existing validator check; and the six-agent set survives every priced merge (refuter+judge saves ~1% and destroys refutation independence; reviewer-absorbing-judge saves zero calls). Priced at the accepted defaults: happy path ≈ 5 calls ≈ $11.7 uncached (~$5.5 cached), the plan gate ≈ 5% of story cost, worst path (revise + reconcile) 9–10 calls ≈ $16; builder-on-Sonnet ≈ 29% saving — and on the sanctioned subscription lane the real metric is tokens-per-allowance. **Two findings are shape-changing, both the same species: a judgment point the catalog names that no roster row covers** — (Z1) the in-run *plan author* (T-B4's plan call belongs to nobody; the roster's planner is interactive, sittings-only, and over-granted for a headless run), and (Z2) the *park-gating critic* (T-C5's adopted rule binds a critic verdict to every park). **The telemetry loop also does not close as drafted** — 05 promises per-phase agent/effort/prompt-version telemetry and a findings-per-model signal for the owner's builder-swap watch item, and the run record carries none of those fields — but every miss is a field pin, not a ruling. 17 pins total; 8 verified.
