## 0. Verdict in one paragraph

Round 1 was applied faithfully. What round 2 found is the next layer down: (1) **`cards ratify` option (a) is not a gate** — the token is a plain file the agent's shell can write, the hook fires only on `draft → ratified`/reopen (a card *born* `ratified`, any re-ratification, and any closure claim by the in-session agent pass untouched), `--no-verify` skips it, ingest cannot tell it ever ran, and mintty Git Bash reports no TTY for the *human*; (2) **the migration has no profile** — under the story profile every one of the 234 live sartor/spolia items lands as `draft`, the 137 closed ones are undefined, and the forbidden `draft → closed` outlaws the brownfield's routine record-only closures; (3) **standalone has no `state.json`**, so `reopens[].closure_id`, the single `[closure]` table, and every rule routed through the sidecar are vacuous for a factory-less project — and a second human closure overwrites the first, which is exactly the history loss the owner forbade; (4) **the build-hash byte layout is not pinned** tightly enough for the stdlib and pydantic hashers to agree, and `ext_schema_hash` inside the prefix makes every extension-schema edit move every closure. Under-called from round 1: `hold` as tending means an in-session agent's tidy commit can clear the owner's "explicit go" holds, and container holds don't propagate. Everything else is fill.

## 2. Fill worklist for draft-2 (mechanics; no ruling needed)

**Hash / canonicalization (I1, I4, I13, I14, A2, A3)**
- G1 Pin the bytes: `sha256(b"schema:"+n+b"\ncanon:"+n+b"\n" + json.dumps(obj, sort_keys=True, separators=(",",":"), ensure_ascii=False).encode("utf-8"))` where `obj` = raw `tomllib` values restricted to the gated keys **before defaulting**, `x` as a nested object of gated keys only, `scope` as the extracted `## Scope` string; same for the claims hash over the claims keys. Drop "in this order of keys" (sorted-key JSON is the order).
- G2 Canonical forms: datetimes `YYYY-MM-DDTHH:MM:SS[.ffffff]Z` (microseconds as parsed; local date-time/time rejected in gated fields); floats shortest repr, `nan`/`inf` rejected; "duplicates rejected" everywhere (not "dedup"); sort = Python `sorted()` on the NFC string / int; `unicodedata.unidata_version` **asserted** against `toolkit.lock` (a lock cannot pin the interpreter's Unicode DB — refuse with a typed error on mismatch); name the `json.dumps` kwargs; `ext_schema_hash` = same canonicalization over `config.toml [extensions]`, a fixed constant when absent.
- G3 One class column: make **M** a plumbing sub-class with an explicit `hashed: yes/no` column (so §5.1 really is generated from §2.1); fix "the four classes … every field is exactly one of these" (there are gated / claims / tending / log / execution + identity plumbing); state `source`'s mutability (set-once).
- G4 Conformance corpus minimum contents: pairs that must hash equal (CRLF/LF, key order, comment, slug rename, tending edit, Updates append, NFC vs NFD source, explicit default vs absent) and pairs that must differ (one scenario char, a `depends_on` element, a `## Scope` word, a gated `x` value, empty vs absent array), each with expected hex — both hashers test against numbers.

**Ingest classifier (I3, I15, A8, A13)**
- G5 §9.5 "ingest classification, pinned": walk `--first-parent` over `cursor..HEAD` on the ratification ref; identity = author email (lower-cased) at the commit (+ `Co-Authored-By` recorded); policy = `config.toml` at that commit; per (commit, card id) compute (before, after) models and emit the **set** {ratification | drift, tending, tending-by-non-tender, log | log.rewritten, claim | claim-drift, status-transition, hold-cleared, id-repair, creation, promotion, deletion, sidecar-edit}; each class decided on its own field subset; multi-class commits emit several events.
- G6 Duplicate-id repair has an actor: `cards repair` run by a ratifier; the repair commit is a qualifying commit for every card it touches (dependents' hashes move); key = (id, path) inside the duplicate window; `D` on `cards/**` and an id change without `renumbered_from` are typed events that block dispatch; promotion = creation with `promoted_from`; the owner may delete under `drafts/` (amend the 1.3 write-set table) or the lander garbage-collects promoted drafts.
- G7 Transition-table fixes: `draft → closed` row per T2; withdrawal "ratifier / tender"; use T-A7's failure-class vocabulary (`budget`/`timeout` are T-A7 classes — cite the row); `terminal(card)` defined once over projected labels and used by both the container roll-up and the drain predicate; epic head `closed` must agree with the roll-up (schema-1 rule); sprint-card projected `closed` = its bound batch `merged`.
- G8 `factory retry` ack lands in `state.json` (`acks[]`, or an answered `questions[]` entry with `source_tag = "retry-ack"`) — the history-complete condition.

**Grammar / log (I8, M7, A13)**
